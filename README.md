# Yama64 Free

Yama64 is a Windows tool for analyzing COBOL source files and Copybooks,
and for viewing fixed-length data files based on the analyzed record layout.

COBOL の階層構造、PIC 定義、項目位置、サイズ、属性などを解析し、
固定長データファイルの内容を項目単位で確認できます。

## Features

- COBOL source / Copybook analysis
- COBOL data structure visualization
- PIC / Offset / Size / attribute display
- Fixed-length data file viewer
- PIC X / PIC 9 / PIC S9 / PIC N
- SIGN LEADING / TRAILING SEPARATE
- COMP / BINARY
- COMP-3 / PACKED DECIMAL
- OCCURS / REDEFINES
- Drag & Drop file loading
- File type detection and Judge dialog
- Record navigation
- Analysis result search

## Requirements

- Windows 10 / 11
- 64-bit Windows
